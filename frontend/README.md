# frontend/

The Astro 5 static site (TypeScript, no UI framework) that organization leaders and CSF staff use. Every page is static HTML plus a client script that calls the Flask JSON API under `/api/*` on the same domain (CloudFront routes it in production). See the root [Layout](../README.md#layout).

## Files

| File | What it does |
|---|---|
| `astro.config.mjs` | `output: "static"`, `trailingSlash: "always"`, directory build format. Adds a dev-only middleware that proxies `/api/*` to `OCI_API` (default `http://127.0.0.1:8000`), because Vite's `server.proxy` loses to Astro's trailing-slash 404. |
| `package.json`, `package-lock.json` | Scripts `dev` (`astro dev`), `build` (`astro build`, output in `dist/`), `preview`, `check` (`astro check`). Only runtime dependency: `astro`. |
| `tsconfig.json` | Extends `astro/tsconfigs/strict`. |
| `.gitignore` | Ignores `node_modules/`, `dist/`, `.astro/`. |
| `src/pages/index.astro` | `/`: organization leader start page. Respondent role, organization name, website, social links and areas to assess; saves `/api/org-meta`, sample organizations via `/api/demo`. Uses `api`, `dom`, `draft`, `icons`. |
| `src/pages/questionnaire.astro` | `/questionnaire/`: first an answer-style chooser (one sample statement in all three styles, kept as `draft.view`, "Change how I answer" to switch), then the statements for the chosen areas, as a checklist, Yes / No for each or one at a time (`quick`), with Spanish text and glossary help from `public/content/`. Submits `POST /api/assessments`. `?area=` answers one shared area, `?demo=1` preloads `sample_answers.json`. Uses `api`, `dom`, `draft`, `icons`, `quick`. |
| `src/pages/results.astro` | `/results/?id=`: the report for the organization (and staff, who get extra views). Polls `/api/assessments/<id>/status`, offers `/retry`. Uses `results`, `coach`, `listen`, `roadmap`, `toc`, `report-ui`. |
| `src/pages/plan.astro` | `/plan/?id=`: the 12-week roadmap page, rendered by `roadmap.mountPlan`. |
| `src/pages/resume.astro` | `/resume/`: paste a resume link or code (`?d=` token) to continue a saved draft, via `draft`. |
| `src/pages/staff.astro` | `/staff/`: CSF staff network dashboard (non-staff are turned away). Filters and tabs from `/api/staff/bi`, `/api/staff/roadmaps`, network PDF `/api/staff/network-report.pdf`; the "Quality and follow-through" tab (`/staff/#quality`) from `/api/staff/quality`, `/api/staff/optins`, `/api/staff/funnel`. Uses `staff-bi`, `staff-ask`, `staff-brief`, `staff-quality`. |
| `src/pages/login.astro` | `/login/`: mocked sign-in (`POST /api/login`), then goes to `?next=` or `/staff/` or `/` by role. |
| `src/pages/404.astro` | Not-found page. |
| `src/layouts/Base.astro` | Shared page shell: imports `global.css`, header (reads `/api/me`, sign-out via `/api/logout`), `title` / `width` / `public` props. |
| `src/components/Icon.astro` | Renders one inline icon from `lib/icons.ts` at build time. |
| `src/lib/*.ts` | Client modules (API client, DOM helpers, report, roadmap, staff dashboard). Per-file table in [src/lib/README.md](src/lib/README.md). |
| `src/styles/global.css` | All styles in one file. Later passes are in sections marked `/* == v1.5 intake == */`, `/* == v1.5 staff == */`, `/* == v1.5 results == */` and the matching `v1.7` sections. |
| `public/content/glossary.json`, `public/content/questions_es.json` | Plain-language glossary and Spanish statement text, generated by `scripts/gen_content.py` then hand-fixed (see root Layout). |
| `public/content/ladders.json` | Groups of laddered statements asked as one multiple-choice question in the one-at-a-time view. |
| `public/content/sample_answers.json` | Synthetic sample B answers for the demo preload. Not real data. |
| `public/favicon.svg` | Site icon. |
| `public/fonts/*` | Atkinson Hyperlegible (4 styles), Noto Sans Math, Source Serif 4 variable, and their OFL licence files. Also used by the PDF report. |

## How it connects

- Dev: run the API on :8000, then `npm run dev` here. Set `OCI_API=http://127.0.0.1:<port>` to point at another API.
- All API calls go through `lib/api.ts` (`/api` prefix, same-origin cookies); a 401 sends the user to `/login/?next=`.
- `npm run build` writes `dist/`, which the deploy scripts publish to S3/CloudFront.

## Changing it safely

- Design rules live outside the repo in `/workshop/design-system/everytown-oci/MASTER.md` (plus page overrides). Put new CSS in the matching `v1.5` section of `global.css` and grep for an existing class name first.
- Escape every API string with `esc()` and URLs with `safeUrl()` (`lib/dom.ts`).
- Run `npm run check` for types.
